StudyLink

Completed

StudyLink is a Windows Forms desktop application developed to connect students with tutors through a simple booking system. The application allows users to enter their personal information, select a subject, choose an available tutor, schedule a tutoring session using a calendar, and receive a booking confirmation. The project was developed to demonstrate desktop application development using C# and the .NET Framework while focusing on usability and user interaction.

Key Features
